## Características Principales

- **Interfaz Futurista:** Fondo interactivo con partículas en Canvas, tipografía Orbitron y Noto Sans JP, e interfaz adaptativa estilizada.
- **Sistema de Autenticación Local:** Inicio de sesión y registro de usuarios con almacenamiento de datos en el navegador (`localStorage`).
- **Comandos y Chat Interactivo:** Soporte para comandos con prefijo personalizable (`.`), búsqueda de imágenes anime (Jikan API) y respuestas automatizadas.
- **Sintetizador de Sonidos (Web Audio API):** Generación de efectos de audio nativos sin dependencias externas pesadas.
- **Soporte Multimedia:** Capacidad para adjuntar imágenes, previsualizar archivos y reproducir contenido en el panel.
- **Diseño Responsivo:** Optimización completa para dispositivos móviles y de escritorio.
